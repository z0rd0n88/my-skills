# yt-audio-fetcher

## `-h` / `--help`

If the argument text (trimmed, case-insensitive) is exactly `-h`, `--help`, or
`help`, output only the block below and stop — do not run any other step in this
skill.

> **⚠️ Writes files to your Downloads folder** — each URL produces an mp3 in
> `/mnt/c/Users/sneak/Downloads/`, overwriting any file already there with the
> same video title.

Downloads the audio of one or more YouTube videos as best-quality mp3s with cover
art and metadata embedded. Reach for it when someone wants the sound from a
YouTube link rather than notes about it — `yteval` is the one that turns a video
into a transcript or writeup.

| Option | Values | Default | Effect |
|---|---|---|---|
| `<url>` (required) | a YouTube video URL — `watch?v=`, `youtu.be/`, `shorts/`, `live/`, `embed/` | — | The video whose audio gets downloaded. Missing or invalid exits 2 without downloading. |
| `<url> ...` (optional) | more YouTube video URLs | — | Each is downloaded in turn. One invalid URL rejects the whole batch up front. |
| `YT_AUDIO_OUT_DIR` (env) | any directory path | `/mnt/c/Users/sneak/Downloads` | Where the mp3s land. |

## Run it

```bash
bash "$HOME/.agents/skills/yt-audio-fetcher/scripts/fetch.sh" <url> [<url> ...]
```

One URL or many — extra URLs are optional and processed in order. Pass the URLs
exactly as the user gave them, quoted, and nothing else. The script owns the
yt-dlp flags, the destination, and the URL check, so there is no reason to
assemble a yt-dlp command by hand; doing so is how the `--no-playlist` guard
gets dropped and a whole radio mix lands in Downloads.

## What it does

- `--no-playlist`, always. A YouTube link copied from a playing video usually carries
  `&list=RD…` (an autogenerated mix). Without this flag yt-dlp would follow it and
  download the entire queue instead of the one video the user asked for.
- Best available audio, converted to mp3 at the highest quality, with the video
  thumbnail as cover art and title/artist metadata embedded.
- Output goes to `/mnt/c/Users/sneak/Downloads/`, named after the video title.
  Override with `YT_AUDIO_OUT_DIR=<dir>` only if the user asks for a different folder.

## Errors

The script exits before downloading anything when:

| Exit | Cause | What to tell the user |
|---|---|---|
| 2 | No URL given | Ask which video they want. |
| 2 | A URL isn't a valid YouTube video link | Name the offending URL. A playlist- or channel-only link has no single video to extract, so it's rejected too. |
| 127 | `yt-dlp` or `ffmpeg` missing | They need installing before this can work. |
| 1 | One or more downloads failed | The script lists which URLs failed; the rest still downloaded. |

A bad URL anywhere in the list stops the whole batch before the first download —
catching a typo early beats discovering it after four files have already landed.

Report the saved file paths back to the user. Relay yt-dlp's own error text
verbatim when a download fails; it names the real cause (age gate, region block,
removed video) far better than a paraphrase.
